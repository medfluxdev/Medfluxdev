# UX Baseline – 2026-10-04 (Phase U0)

Measured before the UI refactoring on branch `feature/ui-refactor`. Plan: `docs/architecture/FRONTEND_UX_ANALYSIS_AND_REFACTORING_PLAN_20261004.md`.

## How to reproduce

```powershell
# Disposable database (Docker, port 55499) – never the product database (port 5432)
.\scripts\run_e2e.ps1            # 8 journeys + screenshots + accessibility
.\scripts\run_e2e.ps1 -Baseline  # record accessibility issues without failing
```

Test data and the test-only login live in `backend/scripts/seed_e2e.py` and `frontend/e2e/.env.example`.

Bugs found while building the journeys:
- **Lost input:** a late data load overwrote what the user had just typed in Stammdaten (fixed in this phase).
- **Lost feedback:** the "Stammdaten gespeichert." confirmation disappears immediately because the page reloads (fixed in U2 with toasts).
